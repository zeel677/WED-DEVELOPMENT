# CampusConnect — Practical 1
Role-Based Student Academic Management System

## Files
- `index.html` — page structure
- `style.css` — responsive design and light/dark themes
- `script.js` — role-based demo login, modules, FAQ, modal, notification, navigation, slider and demo form interactions

## Run
1. Keep all three files in the same folder.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Choose Student, Faculty, or Administrator.
4. Enter any non-empty name/ID and password.

## Important
This is a front-end practical/demo. Login is simulated; data is sample data and is not saved to a database. Real authentication, authorization, file uploads/downloads and persistent records require a backend and database.
